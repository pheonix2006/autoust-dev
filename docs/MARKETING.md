# AutoStudy 对外介绍

AutoStudy 是一个多学期、多课程的本地学习工作区。用户在一个项目里使用两个独立仓库：Canvas CLI 访问课程平台，AutoStudy 提供归档结构、来源调查和按需任务指引。

课程材料、笔记和作业归属于同一课程；学期总览集中链接截止日期、变化与成果。模型先调查真实来源，再保留简洁总结与短计划，自主制作和验证，不强制固定流水线。

初始化、功能与边界以 [README](../README.md) 为准，文件位置以 [学习工作区规范](workspace-layout.md) 为准。不得把历史里程碑验证包装成当前所有运行环境都已支持的能力。每日巡检只在用户要求后安排；个人资料保持本地；Canvas 提交需明确授权。
