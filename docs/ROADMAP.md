# AutoStudy Roadmap

当前定位是多学期、多课程的学习工作区，见 [目录规范](workspace-layout.md)。Canvas CLI 和 AutoStudy 独立维护，在同一个学习项目中使用。

## 当前主线

- 全部新数据按学期归档，课程内聚合课件、笔记和作业。
- 状态扫描保留精确 Canvas IDs，生成建议和链接，不自动执行整个作业列表。
- 默认作业先全面调查，再简洁总结和编写一份 `pipeline.md`，自主执行与验证。继续、修改和修复共用此流程。
- 每日巡检维护学期总览、变化与来源缺口；定时行为遵循用户的时间、范围和通知偏好。
- Skills 是按需领域补充，已有通用能力优先复用。

## 后续改进方向

完善目录迁移兼容性、跨学期总览、来源版本关联、课程内共享资料复用，以及不同运行环境的初始化体验。先验证实际工作效果，再增加辅助脚本；不把更强的模型能力重新锁进固定流水线。

旧 M1–M3.5 设计与验证记录保留在历史文档和 Git 历史中，不能作为当前实现状态。历史 staged 模式仅显式启用。此路线图不是所有能力已经通过端到端验证的声明；具体发布依据相关测试与验证记录。
